# AOC Coordinates Reference

This document lists important coordinates (level IDs) in the Area of Conquest (AOC) event.

## Important Locations

| Location | Level ID | Description |
|----------|----------|-------------|
| **Midtown** | 1 | Central town location |
| **Verdant** | 123 | Verdant location |
| **Monbridge** | 112 | Monbridge location |
| **Moongrave** | 359 | Moongrave location |

## Base Positions

| Base | Level ID | Description |
|------|----------|-------------|
| Left Upper Base | 693 | Starting position for left upper base |
| Right Bottom Base | 696 | Starting position for right bottom base |

## Notes

- Level IDs are used in `clanDomination_move` API calls to navigate the map
- The midtown (level 1) is the central objective in most AOC strategies
- Base positions vary depending on clan assignment
